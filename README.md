# Nmap Network Scanning Project
## project overview
This project demonstrates basic network discovery and scanning using Nmap on an autorized lab network
## Objective
- Understanding network discovery.
- Identify devices on a lab network.
- Learn about open ports.
- Understand basic network security.
## Tools Used 
- Kali LInux
- Nmap
- Vitual box
## Practical Exercises
### 1. check Nmap Version
command:
Nmap --version
### 2. Identify Local IP Address 
Command:sc
IP addr
### 3. Scan Localhost
command:
nmap 127.0.0.1
